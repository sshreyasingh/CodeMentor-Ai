# 🚀 CodeMentor AI

CodeMentor AI is an AI-powered code review and learning platform that helps developers understand, analyze, and improve code through real-time collaboration and intelligent feedback.

## ✨ Features

- 🤖 AI-powered code reviews and suggestions
- 📚 AI Code Tutor for beginner-friendly explanations
- 🏗️ Project architecture and file structure analysis
- 🔄 Execution flow visualization
- 📝 AI-generated project summaries
- 🎯 Resume skill extraction from projects
- 👨‍💻 Real-time collaborative coding with Socket.IO
- 🔐 GitHub OAuth authentication

## 🛠️ Tech Stack

**Frontend**
- React.js
- Socket.IO Client
- Axios

**Backend**
- Node.js
- Express.js
- Socket.IO
- Passport.js

**Database**
- MongoDB Atlas

**AI**
- OpenRouter API
- DeepSeek Models

**Deployment**
- Vercel (Frontend)
- Render (Backend)

## ⚙️ Installation

### Backend

```bash
cd backend
npm install
npm start
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

## 🔑 Environment Variables

### Backend

```env
MONGODB_URI=
JWT_SECRET=
GITHUB_CLIENT_ID=
GITHUB_CLIENT_SECRET=
OPENROUTER_API_KEY=
CLIENT_URL=
```

### Frontend

```env
VITE_API_URL=
```
